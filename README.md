# LLM-chan stickers

Chibi stickers of the "LLM-chan" (大模型娘) - the community's anime personas of large language models - plus Textus-chan, the mascot of the [Textus](https://github.com/CatVinci-Studio/Textus) editor. Eight expressions and eight poses each, on transparent backgrounds, ready for WeChat, Telegram, QQ, Discord or Slack.

大模型娘 Q 版表情包：社区里大家熟悉的各家模型拟人形象，加上 [Textus](https://github.com/CatVinci-Studio/Textus) 的吉祥物 Textus 娘。每个角色 8 个表情、8 个动作，透明背景，可直接用在微信、QQ、Telegram、Discord、Slack。

## Files / 文件

```
stickers/<character>/expressions/512/01-smile.png ... 08-teary.png
stickers/<character>/poses/512/01-writing.png ... 08-asleep.png
stickers/textus/stickers/512/01-heart.png ... 08-cheer.png
```

Every sticker comes in 512 × 512 (Telegram, Discord) and 240 × 240 (WeChat, QQ), PNG with a transparent background. Claude 娘 and 文心一言娘 have a second set of expressions in `expressions-alt/`.

每张都有 512 × 512（Telegram、Discord）和 240 × 240（微信、QQ）两种尺寸，透明背景 PNG。

- Expressions / 表情：smile 微笑 · calm 平静 · surprised 惊讶 · shy 害羞 · pouting 鼓腮 · giggle 偷笑 · focused 认真 · teary 委屈
- Poses / 动作：writing 写字 · daydream 发呆 · dozing 打盹 · happy 开心 · surprised 惊讶 · curious 好奇 · celebrate 庆祝 · asleep 睡着
